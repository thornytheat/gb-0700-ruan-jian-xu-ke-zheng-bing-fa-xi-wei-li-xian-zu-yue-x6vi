# 席位定义

lease_id、user保持字符串。CAD-Pro、cad归一为CAD。kind取online、offline、heartbeat、release、capacity。start/end必须带时区并转换UTC。seats为正整数；capacity记录表示采购生效区间的席位上限。

在线租约可由同租约同版本release提前结束；离线授权一直占用至原到期时刻，即使收到release仍保留。心跳不建立租约。租约采用最高版本；同版多条实体租约冲突隔离。采购区间可重叠，最高version优先，同最高版不同数量返回CAPACITY_CONFLICT。

并发使用半开区间[a,b)，结束同刻开始不重叠。采购边界必须切分并发段。超用责任按租约开始时间倒序、再按编号倒序分配，分配席位严格等于超用数量。超用席位小时为超用数量×秒数/3600，Decimal计算。此工具只核验约定席位数，不含厂商复杂许可证条款。

租约ID在产品内唯一；不同产品允许相同租约号。线上租约在start同刻release得到零时占用，离线仍保留原到期。

# 结算与追溯调整

结算以某一批次（run）的许可结果为原结算依据，登记时冻结：批次编号与摘要、规则版本、复核版本与决定、采购合同（capacity记录）、原始超用剖面与金额。原结算依据此后只读，不再被改写。

当前许可结果取该结算产品范围内最新批次，始终按最新合同计算超用，不沿用旧上限。

采购规则追溯更新后按生效点（带时区的ISO时间）追加一笔与原结算关联的调整。生效点之前保留已确认的超用剖面；生效点之后整体替换为新合同的超用剖面。调整金额=替换后金额−替换前金额：正数记补收，负数记冲减，零记无差异。同一区间只替换一次，不会重复收费。

每笔调整记录调整前后金额、逐区间差额、来源批次与摘要、调整前后规则版本、幂等键。期间确认金额=原确认金额+各调整金额之和，逐位可复算。

生效点之前无超用、之后有超用或反之的区间同样按上述差额处理。结算金额量化到 1e-6 席位小时；同产品逐区间差额之和等于该产品差额，产品差额之和等于调整总额。

# 一致性与重试

调整在单个数据库事务内写调整记录并推进结算版本。中断则整体回滚，已确认的旧版金额与剖面保持可对账。

幂等键在结算内唯一。同一幂等键、同一批次的重复提交返回已有调整，不新增金额；同一幂等键对应不同批次或不同生效点时拒绝（409）。

一个批次只能登记一笔原结算；重复登记返回原结算，不产生第二笔。已作为其他结算调整来源的批次不能再单独登记（409），否则同一段席位会同时计入两笔结算。
